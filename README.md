# partpay
![test](https://github.com/Keishi1015/partpay/actions/workflows/test.yml/badge.svg)

アルバイトの給料を計算するコマンドです。
標準入力から勤務開始時刻と勤務終了時刻を読み取り、給料を標準出力に表示します。

## 概要

勤務時間と時給をもとに給料を計算します。
休憩時間、残業割増、深夜割増を考慮した計算ができます。

## 主な機能

- 勤務開始時刻と勤務終了時刻から給料を計算
- 時給の変更（初期値は1400円）
- 休憩時間の自動計算と手動指定
- 実労働時間が8時間を超えた場合の残業割増
- 22時から翌朝5時までの深夜割増
- 残業割増と深夜割増の重複処理
- 日付をまたぐ勤務への対応
- 複数日の給料の合計計算
- 休憩時間が不足している場合の警告
- 不正な入力に対するエラー処理

## インストール方法

以下のコマンドを実行してください。

```bash
git clone https://github.com/Keishi1015/partpay.git
cd partpay
chmod +x partpay
```

## 使い方

勤務開始時刻と勤務終了時刻を、空白で区切って標準入力に与えます。
給料は円単位で標準出力に表示されます。

### 基本的な使い方

```bash
$ echo "9:00 10:00" | ./partpay
1400
```

### 複数日の給料を計算する場合

1行につき1日分の勤務時間を入力します。

```bash
$ printf "9:00 10:00\n10:00 12:00\n" | ./partpay
1400
2800
```

### ファイルから読み込む場合

勤務時間を記載したテキストファイルからも計算できます。

work.txtの内容

```
9:00 10:00
10:00 12:00
```

実行例

```bash
$ cat work.txt | ./partpay
1400
2800
```

## オプション

| オプション | 説明 |
| --- | --- |
| `-w`, `--wage` | 時給を指定する（初期値：1400円） |
| `-t`, `--total` | 全勤務日の給料の合計を表示する |
| `-h`, `--help` | コマンドの使い方を表示する |

### 時給を変更する場合

```bash
$ echo "9:00 10:00" | ./partpay -w 1500
1500
```

### 給料の合計を計算する場合

```bash
$ printf "9:00 10:00\n10:00 12:00\n" | ./partpay -t
4200
```

### オプションを組み合わせる場合

```bash
$ printf "9:00 10:00\n10:00 12:00\n" | ./partpay -w 1500 -t
4500
```

## 給料の計算仕様

### 休憩時間

休憩時間を省略した場合は、拘束時間に応じて以下の休憩時間を自動的に差し引きます。

| 拘束時間 | 休憩時間 |
| --- | --- |
| 6時間以下 | 0分 |
| 6時間超〜8時間45分以下 | 45分 |
| 8時間45分超 | 60分 |

```bash
$ echo "9:00 18:00" | ./partpay
11200
```

休憩時間を手動で指定する場合は、3列目に休憩時間を分単位で入力します。

```bash
$ echo "9:00 18:00 90" | ./partpay
10500
```

休憩時間は、深夜時間帯以外の早い時刻から優先的に差し引きます。
それでも不足する場合は、深夜時間帯の早い時刻から差し引きます。

### 残業割増

1日の実労働時間が8時間を超えた場合、超過した時間の時給を1.25倍にします。

```bash
$ echo "9:00 19:00" | ./partpay
12950
```

### 深夜割増

22時から翌朝5時までの勤務については、時給を1.25倍にします。

```bash
$ echo "22:00 23:00" | ./partpay
1750
```

### 残業割増と深夜割増の重複

残業時間と深夜時間が重複する場合は、両方の割増を加算します。

| 勤務条件 | 時給倍率 |
| --- | --- |
| 通常勤務 | 1.00倍 |
| 残業勤務 | 1.25倍 |
| 深夜勤務 | 1.25倍 |
| 残業かつ深夜勤務 | 1.50倍 |

```bash
$ echo "13:00 23:00" | ./partpay
13300
```

### 日付をまたぐ勤務

終了時刻が開始時刻より前の場合は、翌日の終了時刻として扱います。

```bash
$ echo "23:00 1:00" | ./partpay
3500
```

### 端数処理

給料は1分単位で計算し、1円未満の端数は四捨五入します。
計算には整数演算を用いることで、浮動小数点による誤差を防いでいます。

```bash
$ echo "22:00 5:00" | ./partpay
10938
```

合計オプションを指定した場合は、全勤務日の給料を合計してから四捨五入します。

## 警告とエラー処理

### 休憩時間の不足

実労働時間に対して休憩時間が不足している場合は、標準エラー出力に警告を表示します。

| 実労働時間 | 必要な休憩時間 |
| --- | --- |
| 6時間以下 | 0分 |
| 6時間超〜8時間以下 | 45分 |
| 8時間超 | 60分 |

```bash
$ echo "9:00 18:00 0" | ./partpay
警告: 1行目: 休憩0分は法定の最低60分より短いです
12950
```

警告が発生した場合も給料の計算は継続します。

### 不正な入力

不正な時刻や休憩時間が入力された場合は、標準エラー出力にエラーメッセージを表示します。

```bash
$ echo "9:60 18:00" | ./partpay
分の範囲が正しくありません
```

不正な入力がある場合は、給料を出力せずに終了します。
空行は読み飛ばしますが、有効な入力が1行もない場合はエラーになります。

### 終了ステータス

| 終了ステータス | 意味 |
| --- | --- |
| 0 | 正常終了 |
| 1 | 不正な入力による異常終了 |
| 2 | 不正なコマンドライン引数 |

## 注意事項

- 休憩時間を省略した場合は、実際の休憩時間ではなく自動計算された休憩時間を使用します。
- 週40時間を超える労働に対する割増や休日割増には対応していません。
- 税金や社会保険料、交通費などは計算に含まれません。
- 本コマンドは給料の概算を求めるためのものであり、実際の給与明細と異なる場合があります。
