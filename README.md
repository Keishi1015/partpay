# partpay
![test](https://github.com/Keishi1015/partpay/actions/workflows/test.yml/badge.svg)

アルバイトの給料を計算するコマンドです。
標準入力から勤務開始時刻と勤務終了時刻を読み取り、給料を標準出力に表示します。

## 概要

勤務時間と時給をもとに給料を計算します。
休憩時間、残業割増、深夜割増を考慮した計算ができます。

## 主な機能

- 勤務開始時刻と勤務終了時刻から給料を計算
- 時給の変更（初期値は1400円）
- 休憩時間の自動計算と手動指定
- 実労働時間が8時間を超えた場合の残業割増
- 22時から翌朝5時までの深夜割増
- 残業割増と深夜割増の重複処理
- 日付をまたぐ勤務への対応
- 複数日の給料の合計計算
- 休憩時間が不足している場合の警告
- 不正な入力に対するエラー処理
